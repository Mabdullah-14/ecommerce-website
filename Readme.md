# 🛒 E-Commerce Website

A fully responsive static E-commerce website built using **HTML5, CSS3, and JavaScript**.  
This project focuses on modern UI design, smooth user experience, and responsive layout across all devices.

---

## 🚀 Key Features

- Fully Responsive Design (Mobile, Tablet, Desktop)
- Modern & Clean User Interface
- Multi-page Layout (8 Pages)
- Interactive UI using JavaScript
- Product Grid System
- Shopping Cart UI
- User Authentication Pages (Login & Signup)
- Smooth Navigation

---

## 📄 Pages Included

### 🏠 Home
Modern landing page with hero section, featured products, and promotional banners.

### 🛍 Shop
Product listing page with clean grid layout and product details.

### 📰 Blog
Informative blog section for news, updates, and articles.

### ℹ️ About
Company introduction, mission, and brand information.

### 📞 Contact
User-friendly contact form for customer communication.

### 🔐 Login
Secure login interface for existing users.

### 📝 Signup
User registration page for creating new accounts.

### 🛒 Cart
Shopping cart page displaying selected items and total price summary.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
